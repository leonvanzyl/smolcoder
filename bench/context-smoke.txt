Build a tiny dependency-free CommonJS math package in this folder. Create separate add.js, subtract.js, multiply.js, divide.js, clamp.js, sum.js files, each exporting its function. Divide must reject zero divisors, clamp takes value/min/max, and sum accepts an array. Create index.js exporting all six functions. Create math.test.js with node:test and strict assertions for each function and errors. Start with a short plan. Write small files with tools, run node --test math.test.js, read index.js to verify exports, and finish the plan. Do not install dependencies.
